Clothing Review Classifier

Text classification pipeline on roughly 19,700 noisy clothing reviews. Covers data cleaning, feature engineering (Count, TF-IDF, embeddings), and logistic regression with k-fold cross-validation. Deployed as a real-time prediction Flask app.

FlirtSense NLP Classifier

DistilBERT-based classifier detecting flirting intent in chat messages. Trained on a 5,000-message synthetic dataset (GPT-generated) with intentional noise and class imbalance to reflect real conversational data. Exposes confidence scores for interpretability on borderline predictions. Achieved 96 to 97% accuracy on held-out data.
